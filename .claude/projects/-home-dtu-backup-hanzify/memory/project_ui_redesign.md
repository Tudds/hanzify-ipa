Plan lưu tại `docs/ui_redesign_plan.md` trong repo.

**Trạng thái:** Chưa bắt đầu — lên plan xong, chưa implement.

**Why:** UI cũ nặng (3D flip, glow orbs, stagger animations, BackdropFilter), không đồng bộ (hardcode pixel/màu/font rải khắp), gradient tràn lan.

**How to apply:** Mỗi session mới, mở `docs/ui_redesign_plan.md`, cập nhật checkbox theo tiến độ. Thứ tự: Phase 1 (shared widgets) → Phase 2 màn nặng nhất (FlashcardStudyView, ConversationScreen, HomeScreen) → các màn còn lại → Phase 3 sweep.
